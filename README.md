# E-commerce-Sales-Analytics-Powerbi
E-commerce sales dashboard using Power BI, Python NumPy, and DAX for revenue, profit, returns, and cancellation analysis.
🛍️ E-Commerce Sales Analytics Dashboard using Power BI

1. 📌 Project Overview

This project focuses on analyzing e-commerce sales performance through an interactive Power BI dashboard inspired by Flipkart's e-commerce environment. It combines Python-based data cleaning with Power BI visualizations to transform sales data into meaningful business insights.

2. 🎯 Project Objectives

- Analyze revenue, profit, and sales performance.
- Identify revenue leakage associated with returned orders.
- Examine order cancellations and their business impact.
- Analyze revenue across different payment methods.
- Present key performance indicators through interactive visualizations.

3. 📂 Data Source

- Used synthetic e-commerce data generated with assistance from Claude AI.
- Cleaned and prepared the dataset using Python and NumPy.
- Used the cleaned dataset for Power BI dashboard development and analysis.

Note: This project uses synthetic data for learning and portfolio demonstration purposes. It does not represent actual Flipkart business data.

4. 🧹 Data Cleaning & Preparation

- Used Python and NumPy for data cleaning and preparation.
- Prepared the dataset for analysis and visualization.
- Added the cleaned dataset to the project files for use in Power BI.

5. 📊 Key Features

- Revenue & Profit Analysis: Monitor financial performance indicators.
- Revenue Leakage Analysis:Analyze the impact of returned revenue using a Waterfall Chart.
- Return Analysis:** Examine returned orders and their revenue impact.
- Order Cancellation Analysis: Explore cancellation-related patterns.
- Payment Method Analysis: Compare revenue across payment methods.
- Interactive Dashboard: Explore key metrics through KPI cards, charts, and visual filters.
